# Contributing Guide

Please review [AGENTS.md](AGENTS.md) and [include/pyrabind/r/AGENTS.md](include/pyrabind/r/AGENTS.md) before submitting changes.

- Keep all repository text, identifiers, comments, tests, and commit messages in English.
- Keep user-facing headers and examples free of Python or R `#ifdef` checks.
- Verify Release builds with strict compiler warnings and run `ctest --test-dir build-release --output-on-failure` cleanly.
